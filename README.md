# 🏫 Next.js Full-Stack School Management App

A full-featured, role-based School Management Dashboard built with **Next.js**, **React**, **Tailwind CSS**, **Prisma**, and **PostgreSQL**.

## 🚀 Features

- 🔐 **Authentication & Authorization** with [Clerk](https://clerk.com)
- 🏫 **Role-Based Access**: Admin, Teachers, Students, and Parents
- 📚 **Dashboard Views** tailored for each user role
- 🎨 **Modern UI** built with Tailwind CSS
- 🗃️ **Database Management** via Prisma ORM and PostgreSQL
- ☁️ **Image Uploads** with [Cloudinary](https://cloudinary.com)
- ✅ Fully typed with **TypeScript**

## 📁 Tech Stack

- **Frontend**: Next.js (App Router), React, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma
- **Database**: PostgreSQL
- **Authentication**: Clerk
- **Image Storage**: Cloudinary
